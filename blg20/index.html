      Deployment class

      —

      The class fixes the transport and the encoding for the life of the record store, because a record written under one bearer has to be sendable, unchanged, under any bearer the unit may fall to. MQTT and JSON are a terrestrial-only privilege: ask for either on a class that includes satellite and the unit refuses, here, at the desk.

      a hostname: letters, digits, hyphen and dot
      5683 plain, 5684 DTLS
      blank = the SIM's own default, which is what most cards want; a managed IoT APN may not resolve DNS
      8–23 letters and digits. Blank keeps the token the unit holds — a token is replaced by a new one or removed by a factory reset, never cleared by omission.

      The unit never reads a token back. It is this unit's data-plane credential, so the read returns that field zeroed and the read-back check skips it. Leave the box blank on any later edit and the unit keeps the token it holds.

      Rules

      —

      A rule turns a stream of readings into two events: one enter and one exit. Hysteresis is what stops a value sitting on the threshold from alarming sixty times a minute — the condition ends at a different value from the one that started it. Hold is how long a state must last before it is reported at all. Latch keeps it raised until somebody clears it (Advanced → “Clear a latched alert”). Renotify repeats it while it is raised, on the one interval below.

      A rule set is applied at the next window boundary, not at the write. The read-back is what is in force, so it may still show the previous set for up to one window — that is the unit being honest, not a failed write.

      iddevicefieldwhenvaluehysteresishold, sseverityflags
      0 = never. One interval for the whole set: twelve bytes a rule had no room for a second period, so the flag is per rule and the period is shared

      Scan options

      —

      What the gateway listens with. Every one of these is a site decision, which is why it is configuration and not a firmware build. Passive is the default: an active scan sends a scan request to every advertiser it hears, which gets the scan response and makes this unit visible to anybody listening. Coded PHY roughly doubles range at a quarter of the throughput and needs a longer window to catch a given advertiser (§23: 57.5 ms against 21.5 ms). Periodic sync receives a scheduled train without scanning for it at all.

      A combination this firmware cannot do is refused with a reason, never silently reduced. If the controller refuses one after the firmware accepted it, the Sessions panel's Scanner row says reduced — that is the case worth looking for, because a site that thinks it is scanning Coded and is not has a hole in it.

      0 = the build default (30 ms)
      window = interval is 100 % duty and is what this firmware has always done
      0 = no floor
      Coded only switches 1M OFF — every phone and most tags advertise on 1M
      sends a scan request per advertiser: needed only when a profile wants the scan response
      one train at a time; cheaper than scanning for the same data

      Access

      —

      What this gateway will and will not ingest. Rules are evaluated in the order below, first match wins; anything no rule matches hits the terminal rule. Only an admitted advertisement gets a short id, a row in the device table, a digest and a record in the store — everything else is counted and forgotten, counted and kept out, or held in the quarantine for you to look at.

      A unit with no list here ingests nothing. An uncommissioned unit quarantines what it hears, so you can see the site before you write a list; a commissioned one drops it. That is deliberate: on a metered — or satellite — link, auto-admission is a bill somebody else writes for you. If the store has stopped growing, read Status → Access → Terminal rule before you suspect the radio.

      The terminal rule, and the defaults

      drop is the default; quarantine is what makes an allow-list usable on a site nobody has surveyed
      0 = no ceiling. A rule may name its own; excess is COUNTED, never queued
      0 = off. The same payload again inside the window is counted, not stored

      The rules, in order

      #actionMAC prefixaddr typecompany idUUID16payload prefixprofilerate/mindedupe s

      A field left blank is not matched on. A rule with every field blank matches everything, which is how "admit the lot" is written. The MAC prefix is 1–6 bytes, written the way it is printed — AC:23:3F — and the payload prefix is up to 8 bytes of hex, matched against the manufacturer or service data after the company id or the UUID.

      Expected devices

      The site's tags, listed before they are heard. An entry admits its device on its own — no rule needed — and pre-assigns its short id in list order, so the platform's numbering is stable from the first advert and is the same on every unit given the same list. One per line: AA:BB:CC:DD:EE:01, profile, label, short id; profile, label and short id may be left off.

      An address that rotates is refused here, with a reason. Pre-assigning a short id to an address that will not exist in fifteen minutes is exactly how a site accumulates ghost rows and presence alerts that can never clear.

      Log

      —

      The last lines both halves printed, newest first. On this board LTE-RESET and BLE-RESET are the same wire, so a debugger on one chip resets the other — this is the only way to read either half's log on a live unit. Fetching asks the cellular half for its ring over the inter-chip link, which costs about 600 ms of a wire that is also carrying records, so it is rate-limited to one fetch every ten seconds.

        Decommission

        —

        This cannot be undone from here. It wipes the credentials, the bonds, the device credentials, the session profiles, the configuration (both copies), the rules, the device table, the stored state and every unsent record. It keeps the byte odometer, the store's wear count and one audit line saying when this happened and which paired device asked for it. The unit ends uncommissioned with its window open, and reports "decommissioned" on its next terrestrial window.
