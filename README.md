# BLG20 Commissioner

Commission an Adsum BLG20 gateway from Chrome over Web Bluetooth — no cable, no app.
Open **https://adsumnetworks.github.io/blg20-commissioner/** in Chrome on Android (or a laptop), stand next to the unit, and follow the five steps.

Built with Adsum IoT Coder · powered by Adsum Networks. Single page, no dependencies, nothing leaves the phone and the gateway except what you export.
