Set up a gateway

Five steps, about three minutes. Stand next to the unit.

1Find the unit

Pick the gateway you are standing next to. When asked, type its passkey.

2Where is it?

Its position goes into every reading. Use this phone's location, standing at the unit.

3Name it

The name you will see on the dashboard. The unit's key is made for you and saved to this phone's register.

4Which sensors are yours?

The unit only stores sensors on its list. These are the ones it hears right now. Untick any that are not yours.

5Finish

Starts the unit, then checks that everything works.

Server (optional)

Only if your installer gave you a server address or a device token. Otherwise the unit uses its built-in defaults.

More

Everything else (network choices, rules, scan timing, sessions, logs, self-test, lights) is in Advanced. Simple never changes those: it leaves the unit's defaults, or what an expert set, as they are.

Commission a gateway

Advanced is the full page as it is today: every panel, every setting. In the real page this mode is the current commissioner, unchanged.

What Simple hides, and why it is safe. Simple writes only: the position, the label, an auto-made identity and key, the accepted sensors, and (if filled) the server and token. It reads the unit first, and if an expert already set rules or network choices it says "3 rules set in Advanced" and leaves them alone. The choice of mode is remembered on this phone.
